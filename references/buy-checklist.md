# 买入前检查清单 · 五维度 25 项

> **用途**：买入前逐项核对，红灯必须 0、黄灯 ≤2 才放行。
> **适用场景**：用户问『这只股票符合我的买入纪律吗』时，加载本文与 valuation.md、financial-analysis.md。
> **来源**：《投资的纪律：从情绪交易到纪律复利》 · ch06.md（读者版见 `/chapters/ch06.html`）
> **规则出处**：数值型规则统一登记在 `rules-index.md`，本文件中的每个数字都能在其中找到 rule_id。


## 三档评分与判定规则

| 档位 | 含义 | 决策规则 |
|---|---|---|
| 通过（绿灯） | 完全符合标准 | 计 0 |
| 警告（黄灯） | 基本符合但有隐忧 | 计 1，买入/持有均 ≤2 个 |
| 不通过（红灯） | 不符合标准，硬约束 | 计 1，必须为 0 才能买入 |

- 买入：红灯 0 个，黄灯≤2 个。
- 持有：红灯 0 个，黄灯≤2 个；黄灯≥3 个启动卖出评估。
- 卖出：出现 1 个红灯，或黄灯累计≥3 个，或卖出触发≥2 项。

## 下单五步

- 第 1 步：算单只上限。单只上限 = 总资产 × 20%，首笔 ≤ 总资产 × 10%。示例：总资产 50 万 → 单只上限 10 万，首笔建仓 ≤ 5 万。
- 第 2 步：算行业上限。行业占比 = 该行业持仓市值之和 ÷ 总资产，上限 30%（大金融合并）。示例：银行+保险+券商 14 万 ÷ 50 万 = 28%，大金融最多再加 2 万。
- 第 3 步：逐项过 25 项，红灯 0 个、黄灯≤2 个才放行。
- 第 4 步：写止损线。止损线 = 买入价 ×（1 − 止损比例）。示例：20 元中线 15% → 20 × 0.85 = 17 元，买入前写入记录。
- 第 5 步：下单，清单归档，标注日期与价格。

## 五维度清单

### 1. 宏观维度

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| M1 | **经济周期位置** | 当前处于复苏或扩张早中期，不在滞胀或衰退期 |
| M2 | **货币政策方向** | 利率处于下行或低位区间，流动性宽松或中性 |
| M3 | **财政政策力度** | 政府支出扩张或至少不收缩，减税降费持续推进 |
| M4 | **地缘政治风险** | 无重大地缘冲突升级，贸易摩擦可控 |
| M5 | **市场整体估值** | 全市场 PE/PB 处于历史中位数以下，或至少不极端高估 |

### 2. 行业维度

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| I1 | **行业空间与增速** | 行业未来 3-5 年 CAGR ≥ 10%，天花板远未触及 |
| I2 | **竞争格局** | CR5 ≥ 50% 或行业正在集中化，龙头份额提升 |
| I3 | **政策环境** | 行业处于政策支持期，无重大监管打压 |
| I4 | **技术变革风险** | 3 年内无颠覆性替代技术出现的可能 |
| I5 | **上下游议价能力** | 行业对上下游议价权评分 ≥ 7/10，不被单一供应商或客户绑架 |

### 3. 公司维度

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| C1 | **商业模式清晰度** | 能用一句话说清楚公司怎么赚钱 |
| C2 | **护城河** | 至少拥有品牌/成本/网络效应/转换成本/规模经济中两项 |
| C3 | **管理层质量** | 实控人专注主业、诚信记录良好、过往承诺兑现率 ≥ 80% |
| C4 | **成长驱动** | 有明确的 3 年以上增长逻辑（渗透率提升/品类扩张/份额提升） |
| C5 | **治理结构** | 无重大关联交易、无频繁变更审计师、股权质押 ≤ 30% |

### 4. 估值维度

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| V1 | **相对估值** | PE/PB/PS 处于自身历史 30% 分位以下，或低于同行业中位数 |
| V2 | **绝对估值** | DCF 或 DDM 测算的内在价值高于当前股价 30% 以上 |
| V3 | **PEG 合理性** | PEG ≤ 1（成长股）或 PE ≤ 无风险利率倒数（价值股） |
| V4 | **安全边际** | 最悲观假设下估值仍有 20% 以上的安全边际 |
| V5 | **估值匹配** | 估值方法与公司类型匹配（周期股看 PB、成长股看 PEG、稳定股看股息率） |

### 5. 风控维度

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| R1 | **仓位上限** | 单只 ≤ 总资金 20%，初始建仓 ≤ 10%，上涨被动 > 25% 已写减仓动作 |
| R2 | **行业集中度** | 单行业 ≤ 30%，大金融（银行/保险/券商）合并计算 |
| R3 | **止损线设定** | 买入前已设硬止损线：短线 5-8%、中线 10-15%、长线 20-25%，触发后冷静 48 小时 |
| R4 | **流动性** | 日均成交额 ≥ 5000 万，不会因流动性不足被"锁死" |
| R5 | **资金来源** | 3 年以上不用的闲钱，零杠杆（房贷除外） |
