# 第九章 复盘

> **用途**：复盘：三层目标 × 五个频次、五类归因阈值、月度五指标、原则生产线。
> **适用场景**：交易复盘与月度复盘；把亏损转成清单修订；区分过程质量与结果。
> **来源**：《投资的纪律：从情绪交易到纪律复利》 · ch09.md（读者版见 `/chapters/ch09.html`）
> **规则出处**：数值型规则统一登记在 `rules-index.md`，本文件中的每个数字都能在其中找到 rule_id。

> 错题本比成绩单值钱：三层频次、两套模板，让每笔亏损变成清单修订。

## 核心观点

- **复盘不是自责，是改规则**：不是后悔药、不是炫耀台、不是表格表演；它是投资系统的迭代工具，是区分能力与运气的手术刀，是从感性下单到理性下单的桥。
- **三时限钉死**：卖出当天记事实，7 天内写归因，3 个月后回访验证。
- **盈利单同样要拆**：单笔盈利里市场 Beta 与运气的成分可达一半以上；盈亏单 100% 都要复盘。
- **盈利不等于做对，亏损不等于做错**：10 笔以内的短期结果，方法与运气都能主导。
- **每条原则必须带数字阈值**：10 分钟扫完全年清单找模式，每条至少 1 个数字，1 个季度验证，同类亏损率 ≤25% 留用。
- **复盘的产出是清单修订**：没进日历的计划，执行率会掉到 0；错误按年清算，学费按笔累加。

## 关键机制/框架

### 机制一：三层目标 × 五个频次

| 层级 | 动作 | 时限 | 合格标准 |
|---|---|---|---|
| 第一层 记录事实 | 买入理由、持有过程、卖出理由全记 | 卖出当天 | 字段 ≥10 项 |
| 第二层 分析归因 | 拆开盈利与亏损的来源 | 7 天内 | 五类归因至少勾 1 项 |
| 第三层 提取原则 | 抽出可复用的规则 | 30 天内 | 规则带数字阈值并进清单 |

| 频次 | 时点 | 必做内容 | 耗时 |
|---|---|---|---|
| 即时复盘 | 卖出当天 | 基本信息 + 卖出分析 | 10 分钟 |
| 冷却复盘 | 卖出后 3-7 天 | 结果归因 + 教训提取 | 20 分钟 |
| 回访复盘 | 卖出后 1-3 个月 | 复看卖后走势，验证判断 | 15 分钟 |
| 月度复盘 | 每月最后交易日 | 全月归因与原则更新 | 2-3 小时 |
| 年度复盘 | 12 月底或 1 月初 | 全年审视与规则修订 | 1 整天 |

### 机制二：五类归因的判定阈值

| 归因 | 判定阈值 |
|---|---|
| 市场 Beta | 组合收益与基准差的绝对值 ≤2 个百分点 |
| 行业配置 | 行业指数涨幅−基准 ≥5 个百分点 |
| 个股选择 | 个股涨幅−行业指数 ≥5 个百分点 |
| 择时操作 | 仓位变动贡献 ≥5 个百分点 |
| 运气 | 买入后 30 天内出现下单时不可预知的重大消息 |

亏损归因对应五项：市场整体下跌、行业板块下跌、个股基本面恶化、买入估值过高（买时估值分位 >80%）、没有及时止损。

### 机制三：月度五指标 + 原则生产线

| 指标 | 公式 | 达标线 |
|---|---|---|
| 胜率 | 盈利笔数 ÷ 总笔数 ×100% | 50%-60% |
| 盈亏比 | 平均盈利金额 ÷ 平均亏损金额 | >2 |
| 最大回撤 | 当月高点到低点的跌幅 | <10%，且 <方案回撤上限 |
| 超额收益 | 组合月收益 − 基准月收益 | >0 |
| 交易频率 | 当月成交笔数 | 2-8 笔；>8 笔过频，<2 笔过疏 |

原则生产线四步：取样（全年交割单与各笔复盘模板）→ 算复发率（同类错误复发率=复发次数÷同类交易次数×100%）→ 提炼规则（每条带 1 个数字阈值并标注修订日期）→ 一个季度后复算验证。

- 计算示例：全年追高单 12 笔、其中 9 笔亏损 → 复发亏损率=9÷12×100%=75%；提炼规则「不在阶段新高追入，等待回调 ≥10%」写入清单；次季度同类亏损率降到 ≤25% 视为有效，否则回到第 1 步重拆。

## 清单与数据

**复盘合格判定（数字阈值）**

| 判断项 | 合格 | 不合格 |
|---|---|---|
| 覆盖率 | 盈亏单 100% 都复盘 | 只复亏损单，覆盖 <100% |
| 时限 | 卖出当天记事实，7 天内交归因 | 归因拖 >7 天 |
| 字段数 | 单笔 ≥10 个字段 | 只记价格与盈亏 |
| 原则产出 | 每月新增或修订 ≥1 条 | 连续 3 个月为 0 条 |
| 执行闭环 | 计划进日历，执行率 ≥80% | 计划不进日历 |

**单笔复盘三步（含计算示例）**

- 第 1 步，导出记录。数据来源：券商 App 交割单导出。
- 第 2 步，算收益率。公式：收益率=(卖出价−买入价)÷买入价×100%。
- 第 3 步，对照止损线归类。止损线口径（买入前设定）：短线 5-8%、中线 10-15%、长线 20-25%。
- 计算示例：买入 12.50 元、卖出 11.00 元 → (11.00−12.50)÷12.50=−12.0%。中线止损线区间 10-15%，−12% 已在区间内却未执行 → 归因勾「没有及时止损」，原则栏写「中线单跌破 −10% 无条件离场」。

**每笔模板五组字段与数字标准**

| 分组 | 字段 | 数字标准 |
|---|---|---|
| 基本信息 | 标的、买卖日期、持有天数、价格、收益率、仓位比例 | 仓位 ≤20%，初始建仓 ≤10%，被动 >25% 减仓 |
| 买入分析 | 一句话理由、市场环境、估值分位、目标价、止损线 | 止损线：短线 5-8% / 中线 10-15% / 长线 20-25% |
| 持有过程 | 最大涨幅、最大跌幅、期间事件、心理状态、加减仓念头 | 单行业 ≤30%；任何加仓先过检查清单 |
| 卖出分析 | 一句话理由、是否触发止损线、是否达目标价、卖后走势 | 触线必须执行，回填执行结果 |
| 归因与教训 | 五类归因勾选、做对做错、重来会怎么走、提炼原则 | 7 天内完成，原则必须带阈值 |

**错误类型记入阈值与纠正时限**

| 错误类型 | 记入阈值 | 纠正时限 |
|---|---|---|
| 选股错误 | 买入后基本面被证伪 | 10 天内写替代标准 |
| 择时错误 | 买在指数当月涨幅前 10% 的位置 | 10 天内复盘下单时点 |
| 仓位错误 | 单只 >20% 或单行业 >30% | 当日修正 |
| 止损错误 | 触线未执行，损失再扩 ≥5 个百分点 | 当日修正 |
| 心态错误 | 未过检查清单就下单，月 ≥1 次 | 次月首周写约束动作 |

**常见原则库（进清单前先过阈值）**

| 分类 | 原则 | 数字阈值 |
|---|---|---|
| 选股 | 只买能讲清商业模式的公司 | 讲不清不买 |
| 选股 | 盈利质量门槛 | ROE 连续 ≥15% |
| 选股 | 负债红线 | 资产负债率 >60% 不碰 |
| 买入 | 分批建仓 | 首笔 ≤10%，合计 ≤20% |
| 买入 | 买入前设止损线 | 短线 5-8% / 中线 10-15% / 长线 20-25% |
| 持有 | 核心仓最少持有期 | ≥1 个完整财报季（≥90 天） |
| 持有 | 行业上限 | 单行业 ≤30% |
| 组合 | 持股与现金 | 8-12 只，核心 5-8 只占 70%-80%；现金 ≥15% |
| 组合 | 零杠杆 | 房贷除外，无融资负债 |
| 卖出 | 触线无条件执行 | 止损线触发即卖出 |
| 卖出 | 再平衡 | 季度检查，偏离 5 个百分点执行 |
| 心态 | 迷茫降频 | 当月 >8 笔即停手一周 |

**危险信号自检表**

| 危险信号 | 判定阈值 |
|---|---|
| 复盘覆盖率 | <100%（只复亏损单） |
| 计划执行率 | <80% |
| 月度复盘缺席 | 全年 ≥2 次 |
| 承认运气次数 | 3 个月内 0 次 |
| 反方证据条数 | 单次复盘 0 条 |

**执行清单**

- [ ] 卖出当天已完成即时复盘（10 分钟内）
- [ ] 收益率已按公式算出，非估算；止损线为买入前设定，非事后补写
- [ ] 7 天内完成归因与教训，3 个月后已安排回访提醒
- [ ] 五组字段全部填齐（≥10 项），五类归因至少勾 1 项且附证据句
- [ ] 五项指标全部算出并对照达标线，每条纠正措施带完成日期
- [ ] 原则库里每条都带 ≥1 个数字阈值并进检查清单
- [ ] 每日 5 分钟 / 每周 30 分钟 / 每月 2-3 小时已进日历
- [ ] 本季度规则执行率 ≥80%，复发率 ≤25%
- [ ] 月度五指标连续记录 ≥3 个月
- [ ] 五个误区与三个案例的缺失清单项已逐条自查
