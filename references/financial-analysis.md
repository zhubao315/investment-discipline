# 第四章 财报

> **用途**：财报阅读：三表联读、10 个关键指标阈值、12 项造假预警、五步筛股漏斗。
> **适用场景**：读一份财报并给出可核查结论；识别财务异常；筛股漏斗的财报层。
> **来源**：《投资的纪律：从情绪交易到纪律复利》 · ch04.md（读者版见 `/chapters/ch04.html`）
> **规则出处**：数值型规则统一登记在 `rules-index.md`，本文件中的每个数字都能在其中找到 rule_id。

> 财报不告诉你买什么，只告诉你别买什么。

## 核心观点

- **财报是排雷器，不是买入指令**：5项硬排除标准先把5000家砍到500-800家；过完五步漏斗只得到5-15家候选池，下单还要过估值与检查清单。
- **钱是真的，比赚得多更重要**：连续5年ROE>15%，但现金流/净利<0.5，照样是危险品。
- **净利可以调节，自由现金流很难造假**：连年高利润而自由现金流连年为负，利润真实性存疑。
- **商誉是最容易暴雷的资产**：占净资产>30%一票否决；2018年差点重仓的白马股，商誉占净资产超70%、经营现金流连续两年不到净利润的一半、应收账款增速是收入增速的3倍，三项全红没买，半年后减值暴雷、股价跌去八成——省下的就是赚到的。
- **同样15%的ROE质量天差地别**：高利润模式（净利率30%×周转0.5×乘数1.0）不靠杠杆；高杠杆模式（净利率3%×周转2.0×乘数2.5）融资一收就塌；杠杆贡献>50%的ROE不作数。
- **财报的价值是逼你停手**：不是帮你找到牛股，而是在你最想买的时候拦下你。

## 关键机制/框架

### 机制一：三张报表联读（现金流组合六态）

利润表链条：营业收入−营业成本=毛利；−三费（销售/管理/财务）=营业利润；±营业外收支=利润总额；−所得税=净利润。
资产负债表：资产=负债+所有者权益；资产水分三大来源是商誉、应收账款、存货。
现金流量表：经营（主业赚的钱，最重要）、投资（扩张期通常为负）、筹资（借钱还钱、发股分红）。

| 经营现金流 | 投资现金流 | 筹资现金流 | 公司状态 |
|---|---|---|---|
| + | - | + | 成长期：主业赚钱、扩张、融资 |
| + | - | - | 成熟期：主业赚钱、扩张、还债分红 |
| + | + | - | 收缩期：主业赚钱、卖资产还债 |
| - | - | + | 危险期：主业不赚钱，靠融资续命 |
| - | + | + | 高危：主业不赚钱，卖资产+借钱 |
| - | + | - | 极高危：主业不赚钱，卖资产还债 |

联读五步：现金流比=经营活动现金流净额÷净利润，>0.8通过；自由现金流=经营现金流−资本支出，>0通过；商誉占比=商誉÷净资产（示例30亿÷200亿=15%，落10-20%关注区）；三项全绿进10指标，任一红灯先按12项预警排雷。

### 机制二：10个关键财务指标（阈值表）

| 指标 | 公式 | 判定阈值 |
|---|---|---|
| ROE | 净利润÷净资产×100% | >15%优秀进入候选；10-15%良好看5年趋势；<10%不进候选；连续5年>15%稀缺重点跟踪 |
| 毛利率 | （收入−成本）÷收入×100% | >50%强定价权；30-50%中等竞争力；<20%薄利；连续2年下降=竞争加剧 |
| 净利率 | 净利润÷收入×100% | >20%优秀；10-20%良好；<5%薄利、经营风险大 |
| 资产负债率 | 总负债÷总资产×100% | <40%保守；40-60%适中；60-70%偿债承压必查有息负债率；>70%高风险直接排除（金融除外） |
| 经营现金流/净利 | 经营现金流净额÷净利润 | >1.0优秀；0.8-1.0良好；0.5-0.8一般（应收偏多）；<0.5危险纸面富贵；<0严重警告直接排雷 |
| 商誉/净资产 | 商誉÷净资产×100% | <10%安全；10-20%需关注；20-30%高风险；>30%极高风险一票否决 |
| 应收周转天数 | 365÷（收入÷应收平均余额） | <30天强势加分；30-90天正常；90-180天回款偏慢；>180天危险 |
| 存货周转天数 | 365÷（营业成本÷存货平均余额） | <60天高效；60-180天正常；180-365天偏慢；>365天危险跌价炸弹 |
| 自由现金流 | 经营现金流净额−资本支出 | 持续为正优秀；自由现金流/净利>0.8利润质量高；持续为负警惕 |
| 分红率 | 现金分红总额÷净利润×100% | >50%大方加分；30-50%正常；<30%保守查再投资回报率；0%须有理由 |

杜邦拆解：ROE = 净利率 × 资产周转率 × 权益乘数；权益乘数<2.0为佳。同样15%的两种ROE——高利润模式（净利率30%、周转率0.5、乘数1.0）质量高不靠杠杆；高杠杆模式（净利率3%、周转率2.0、乘数2.5）质量低，融资一收就塌。

### 机制三：财务造假12项预警（N值评分）

| # | 表现 | 检测公式与阈值 | 权重 |
|---|---|---|---|
| 1 | 收入大涨，现金流不跟 | 现金流/净利连续<0.5即警 | 高 |
| 2 | 毛利率异常高于同行 | 对比≥5家同行，偏差>15个百分点要查 | 高 |
| 3 | 频繁变更会计政策 | 查年报"重大会计政策变更"章节及前后影响 | 中 |
| 4 | 利润靠补贴与处置 | 净利30%以上来自非经常项；扣非/净利<0.7即警 | 中 |
| 5 | 应收异常增长 | 收入+10%而应收+50%即典型；应收/收入>30%且连升即警 | 高 |
| 6 | 存货异常增长 | 存货增速÷成本增速连升2年即警 | 中 |
| 7 | 商誉过高+承诺变脸 | 商誉/净资产>30%；标的业绩承诺完成率<100%即高危 | 高 |
| 8 | 其他应收/应付挂账 | 金额大、挂账超1年、对手为关联方或自然人即警 | 中 |
| 9 | 在建工程长期不转固 | 金额大且超2年不转固，对比同行工期 | 中 |
| 10 | 经营现金流靠"其他"撑 | "收到其他与经营有关的现金"占比>30%且附注不透明即警 | 高 |
| 11 | 关联交易灌现金流 | 关联交易占收入或现金流>20%即警 | 高 |
| 12 | 存钱与借钱并存 | 账上现金>50亿仍大额借款，查受限资金与借款利率 | 高 |

| 触发个数N | 结论 | 动作 |
|---|---|---|
| 0-1 | 安全 | 进下一步 |
| 2-3 | 关注 | 深挖附注与问询函 |
| 4-5 | 警惕 | 回避 |
| ≥6 | 远离 | 一票否决 |

### 机制四：五步筛股漏斗（5000进5-15）

漏斗一行版：5000→500-800→100-200→50-100→20-50→5-15→3-5。

| 步骤 | 阈值 | 通过后余量 |
|---|---|---|
| 第1步 排雷5项 | 资产负债率>70%（金融除外）；现金流/净利<0连续2年；商誉/净资产>30%；审计意见非"标准无保留"；12项预警触发≥4项 | 500-800家 |
| 第2步 盈利能力 | ROE连续5年>15%；毛利率连续5年>30%；净利率连续5年>10% | 100-200家 |
| 第3步 盈利质量 | 现金流/净利5年均值>0.8；自由现金流连续3年为正；应收周转天数<90天且无连升趋势；存货周转天数<180天且无连升趋势 | 50-100家 |
| 第4步 成长性 | 收入5年复合增速>10%；净利5年复合增速>10%；增长驱动非一次性因素 | 20-50家 |
| 第5步 估值 | PE低于行业中位数或自身历史中位数；PEG≤1.5；DCF安全边际≥30% | 5-15家候选池 |

收敛后：5-15家进深度研究（行业、公司、管理层三件套），收敛到3-5家核心持仓，单只初始建仓≤10%、上限20%。

## 清单与数据

### 每份财报必查20项

**利润表**

- [ ] 收入增速落在10-20%区间
- [ ] 毛利率连续下降未超3个百分点
- [ ] 三费率无单年升5个百分点
- [ ] 扣非/净利≥0.7
- [ ] 净利增速未超收入增速2倍

**资产负债表**

- [ ] 货币资金覆盖短期负债1倍以上
- [ ] 应收增速未超收入增速1倍
- [ ] 存货增速未超成本增速1倍
- [ ] 商誉/净资产<30%
- [ ] 资产负债率<70%（金融除外）

**现金流量表**

- [ ] 经营现金流为正
- [ ] 现金流比≥0.8
- [ ] 自由现金流为正且/净利>0.8
- [ ] 现金流组合已归类

**交叉验证**

- [ ] 收入与税金偏差≤15个百分点
- [ ] 收入与现金偏差≤15个百分点
- [ ] 人均创收单年增幅≤30%

**综合判断**

- [ ] 审计意见为标准无保留
- [ ] 12项预警N≤1
- [ ] 杜邦驱动因素已判定，杠杆乘数<2.0加分

### 交叉验证四式

| 式 | 公式 | 阈值 | 来源 |
|---|---|---|---|
| 税金式 | 收入×13%（销项税≈营业收入×13%） | 偏差>15个百分点 | 利润表+税项附注 |
| 现金式 | 收入×1.13−应收增额 | 偏差>15个百分点 | 现金流量表 |
| 员工式 | 收入÷员工人数 | 单年突增>30% | 附注员工情况 |
| 产能式 | 产能×产能利用率×单价 | 报告收入超理论值即疑 | 经营分析章节 |

### 五大陷阱

| 陷阱 | 手法 | 识别阈值 |
|---|---|---|
| 大洗澡 | 集中计提减值，一次亏个够 | 某年巨亏而营收未大降、减值超往年3倍 |
| 寅吃卯粮 | 提前确认收入、推迟费用 | Q4收入占全年>45%，或年末应收激增 |
| 关联交易造利润 | 左手倒右手 | 关联交易占比>20% |
| 资本化费用 | 本该费用化却资本化 | 资本化比例单年升10个百分点以上 |
| 现金理财幻觉 | 高现金+高借款 | 受限资金占比>30% |

### 季报五看

| 看点 | 健康信号 | 危险信号 |
|---|---|---|
| 收入增速 | 符合全年预期节奏 | 单季转负 |
| 净利增速 | 与收入同步 | 差2倍以上 |
| 经营现金流 | 为正且匹配利润 | 连续2季为负 |
| 毛利率 | 波动<3个百分点 | 单季降>3个百分点 |
| 环比 | Q2≥Q1 | 环比下滑即跟踪 |
