# 第三章 行业：先选行

> **用途**：行业分析：五力实操、生命周期四相定位、格局判断与行业分、六大警戒线。
> **适用场景**：判断一个行业能不能碰；识别行业层面的排除项；行业间比选。
> **来源**：《投资的纪律：从情绪交易到纪律复利》 · ch03.md（读者版见 `/chapters/ch03.html`）
> **规则出处**：数值型规则统一登记在 `rules-index.md`，本文件中的每个数字都能在其中找到 rule_id。

> 行业看走眼，好公司照样亏钱。

## 核心观点

- **选股先选行，选行先看势，看势先算数**：五力、CR3/HHI、生命周期各打一项分，合成行业分——行业分析是证据链，产出是带数字阈值的表，不是"必涨"话术。
- **先过行业关再谈个股**：单行业≤30%，单只≤20%（初始≤10%）；行业逻辑破坏即触发止损线与再平衡，季度偏离5个百分点即执行。
- **热度不等于景气，需求增速不等于利润增速**：2023年光伏行业需求同比+30%，A光伏龙头利润反而下滑——资本涌入造成过剩，先查产能利用率是否<70%、CR3是否恶化。
- **好行业配贵估值照样亏**：2021年初核心资产抱团板块处历史90%以上分位，随后最大回撤超50%；行业分再高，安全边际>30%才买。
- **政策有滞后、方向也会变**：2021年教培监管落地，板块年内最大回撤超70%——仓位上限是政策风险的最后一道保险。
- **格局比增速更决定赚钱能力**：快递行业持续增长，但价格战令龙头净利率一度跌破3%；优先选CR3提升、价格战停火的格局。

## 关键机制/框架

### 机制一：五力实操（每力一张判断表）

五力 = 现有竞争、潜在进入者、替代品、供应商、买方。

现有竞争者打分：CR3>60%得3分（寡头垄断，竞争温和，可进候选池），30%-60%得2分，<30%得1分（充分竞争，谨慎）；HHI>2500加1分（高度集中），<1000减1分（高度分散）。

进入壁垒评分表（四项打分，总分4-12）：

| 壁垒类型 | 高（3分） | 中（2分） | 低（1分） |
|---|---|---|---|
| 资本壁垒 | 新建达经济规模需>10亿 | 1-10亿 | <1亿 |
| 技术壁垒 | 核心专利保护 | 工艺积累 | 可复制 |
| 政策壁垒 | 牌照管制 | 资质要求 | 自由进入 |
| 品牌壁垒 | 强品牌认知 | 有一定认知 | 无差异 |

判定线：总分10-12分=高壁垒，新进入者威胁低；7-9分=中等壁垒；4-6分=低壁垒，威胁高。

替代品渗透率四阶段：

| 渗透率阶段 | 阈值 | 含义 | 动作 |
|---|---|---|---|
| 导入期 | <10% | 替代尚远 | 常规跟踪 |
| 加速期 | 10%-30% | 快速替代 | 每季更新渗透率 |
| 拐点期 | 30%-40% | 增速将放缓 | 重估被替代行业空间 |
| 主流期 | >40% | 替代完成大半 | 被替代方按衰退期管理 |

年均提升8-10个百分点为快替代（新能源车渗透率5%（2020）→30%（2023）→约50%（2025））。

供应商与买方的数字线：

- 供应商：关键料CR3>70%即议价能力强；认证/转换周期>1年为强；原材料涨价时毛利率连续2个季度下滑超过3个百分点即预警。
- 买方：前5大客户收入占比>50%议价强、30%-50%中等、<30%有利；产品同质化+低转换成本同时成立即毛利率预警。

### 机制二：生命周期四相（定位×仓位）

| 指标 | 萌芽期 | 成长期 | 成熟期 | 衰退期 |
|---|---|---|---|---|
| 行业增速 | >50% | 20%-50% | 5%-15% | <0% |
| 龙头利润率 | 普遍亏损 | 净利率<5% | 净利率5%-15%稳定 | 连续2年下滑 |
| 资本开支增速 | >30% | 20%-30% | 5%-15% | <0% |
| 年新进入者 | >10家 | 3-10家 | <3家 | 约0家 |
| 行业集中度 | CR3<25% | CR3 25%-45%提升中 | CR3>45% | CR3>45%或份额下降 |

| 阶段 | 典型样本（年份） | 风险 | 仓位 | 买卖阈值 |
|---|---|---|---|---|
| 萌芽期 | 2015年新能源车、2020年元宇宙、2023年AIGC | 失败率>80% | ≤5% | 技术路线被证伪即退出 |
| 成长期 | 2020-2023年光伏、2021-2025年新能源车 | 高 | 10%-20% | 调整期买；PE>60倍或增速跌破20%下限即卖 |
| 成熟期 | 白酒、家电、银行、保险 | 中低 | 20%-30% | PE低于历史均值买，持有吃分红 |
| 衰退期 | 传统燃油车、功能手机、传统媒体 | 高 | ≤5%或不参与 | 趋势确认衰退即退出 |

定档规则：四项指标中三项命中即定档；仓位与单行业≤30%上限取孰低；萌芽与衰退期合计不超过总仓位10%。

### 机制三：格局判断与行业分合成

集中度标准：CR3——>75%极高 / 45%-75%高 / 25%-45%中 / <25%低；HHI（各家份额平方求和，0-10000）——>2500高度集中 / 1500-2500中度 / <1500低度。

| 格局类型 | 特征阈值 | 策略 |
|---|---|---|
| 一超多强 | 一家>40%，其余<15% | 买龙头 |
| 双寡头 | 两家各>25%，其余<10% | 买两家龙头或成本更低者 |
| 多强并立 | 3-5家各>10%，无一家>30% | 买竞争优势最强者，或等整合 |
| 高度分散 | 无一家>10% | 谨慎参与，等整合机会 |

三种竞争优势的数字线：成本优势=毛利率高于同行≥5个百分点；差异化优势=售价高同行10%以上且份额同比+1个百分点以上；转换成本=客户留存率>90%、复购率>60%。

**行业分合成公式**：行业分 = 五力均分×0.4 + 生命周期分×0.3 + 格局分×0.3（生命周期分：萌芽1、成长3、成熟2、衰退1；格局分：一超/双寡3、多强2、分散1）；≥2.5进候选池，写入I1-I5。

## 清单与数据

### 六大行业警戒线（每业一张指标表）

| 行业 | 健康 | 危险 |
|---|---|---|
| 半导体 | 研发投入占收入比>15%；进入14nm及以下；库存周期回升段（周期长约3-4年） | 研发<10%；停留在成熟制程且无订单；周期顶部去库开始 |
| 新能源 | 产能利用率>85%；出口增速同比>20% | 产能利用率<70%（过剩警戒）；毛利率连续2季下滑>3个百分点；出口同比<0% |
| AI | 算力收入增速同比>50%；研发占比>15%；付费转化率>10% | 算力增速<20%；研发<8%；ARPU连续2季下滑 |
| 消费 | 同店增速>0%；毛利率高于同行≥3个百分点；库存周转天数同比下降；经营现金流/净利润>1 | 同店连续2季<-5%；毛利率连续2季下滑>2个百分点；库存周转同比上升>20%；现金流比连续2年<0.7 |
| 医药 | 在研管线阶段III以上≥3个；研发费用占比>10%；创新药收入占比>30% | 核心管线失败2次；研发<5%且无新品；创新药占比<10%且下滑；核心品种丢标 |
| 金融 | ROE>10%；不良率<1.5%；拨备覆盖率>150%；股息率>3%；净息差>1.5% | ROE<8%且连降2年；不良率>2%；拨备<120%；分红连续2年为0；净息差<1.2% |

### 七误区速查表

| 误区 | 数字化应对阈值 |
|---|---|
| 增速幻觉 | 产能利用率<70%即预警 |
| 外推历史 | 阶段判断先于历史收益 |
| 忽视格局 | CR3恶化（降>3个百分点）即降级 |
| 盲信政策 | 单行业≤30%硬上限 |
| 忽视估值 | 安全边际>30%才买 |
| 线性外推 | 渗透率>30%-40%重估 |
| 忽视传导 | 选议价强环节（CR3>70%） |

### 六步流程

| 步骤 | 动作 | 产出 |
|---|---|---|
| 第1步 行业概况 | 定义边界（主业收入占比≥70%才归入该行业）、规模与增速、产业链图谱、前10-15家名单 | 概况一页纸 |
| 第2步 宏观环境 | PEST四栏：政治、经济、社会、技术；政策梳理 | 政策风险项 |
| 第3步 竞争格局 | 算CR3/CR5/HHI，判格局类型，评三种优势 | 格局打分 |
| 第4步 生命周期 | 定位四阶段，识别拐点，预测增速 | 阶段与仓位区间 |
| 第5步 机会判断 | 合成行业分，配估值（安全边际>30%），列风险 | 候选行业≤3个 |
| 第6步 持续跟踪 | 关键指标监控，每季更新，逻辑变了即修正（超过180天未更新即返工） | 季度更新记录 |

### 组合口径同步核对

持股8-12只（核心5-8只占70-80%）、单只≤20%（初始≤10%）、单行业≤30%、现金≥15%、零杠杆；个股止损线按短线5-8%、中线10-15%、长线20-25%三档买入前设定；每季度检查再平衡，偏离目标5个百分点即执行。
